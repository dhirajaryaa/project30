## What I did

Built the Open Graph image pipeline. Every important page now generates a unique OG image at build time using Next.js `ImageResponse`. The profile page shows the goal, area, current day. Day pages show the task and status. The landing page has its own brand card.

Set `og:site_name` across all pages. Verified every OG route returns 200 with correct `image/png` content type using curl during dev.

## What I learned

OG images are the first impression most people get when a link is shared. A static PNG generated at build time with proper typography and hierarchy beats any dynamic card injection. The `siteName` meta tag was missing on public profile routes — a small detail that social platforms actually check.
